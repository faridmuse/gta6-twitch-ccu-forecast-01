Forecast GTA VI's launch-day Twitch viewers hour by hour: an anchor-and-shape forecast in log space. Hour 1's print anchors the scale; the shape (the ratio of each later hour to hour 1) comes from past big launches with the same rolling midnight-local console unlock, with a scale adjustment — big launches have flatter ratio curves than small ones — fitted on the launches the case file ships. Mean pinball loss 0.177 on the four practice launches (house baseline: 0.387).

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
